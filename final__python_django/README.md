# Итоговый проект: Интернет-магазин «Megano»

- Автор: Евгений Тявкин

- Куратор: Роман Андреев

## Описание проекта
**Цель проекта:** разработка полнофункционального веб-приложения интернет-магазина 
на базе фреймворка Django с реализацией REST API для взаимодействия с клиентской 
частью.

## Техническая реализация
Проект разработан в соответствии с техническим заданием на итоговую квалификационную 
работу. Архитектура приложения включает:

**Фронтенд:** готовая клиентская часть, интегрированная с API.

**Бэкенд:** реализация серверной части на Django с REST API.

**Система контроля версий:** Git workflow для организации командной разработки.

## Особенности разработки
В рамках проекта была выполнена индивидуальная разработка REST API для 
взаимодействия с клиентской частью в соответствии с предоставленным контрактом.
Использована версия Django 5.1, которая являлась последней на момент начала работы над проектом.
Для взаимодействия с клиентской частью применена актуальная версия REST Framework 3.15. 
В качестве базы данных использована стандартная SQLite3, возможностей которой 
для данного проекта оказалось достаточно.

В процессе реализации создано приложение `api`, содержащее общие функции и 
классы для всех остальных приложений. Такое решение позволило избежать циклических 
ссылок между модулями проекта. Для этого приложения написаны тесты для проверки 
общих функций.

Далее были разработаны следующие приложения:
- `user` — для управления аутентификацией, регистрацией пользователей, профилем 
активного пользователя, а также для смены аватара и пароля.
- `product` — для работы с продуктами, включая категории, теги, изображения 
и распродажи. Через панель администратора возможно добавление продуктов и сопутствующей информации.
- `order` — для управления покупками и работы с корзиной товаров.

Каждое приложение содержит собственные модели таблиц, view-функции, сериализаторы, 
тесты и другие компоненты. Такое модульное разделение обеспечивает удобочитаемость 
кода и упрощает его дальнейшее сопровождение. Детальное документирование объектов 
и комментарии в коде дополнительно облегчают поддержку проекта.

Безопасность приложения обеспечена за счёт встроенных механизмов контроля прав доступа Django. 
Стабильность работы достигнута благодаря дополнительным проверкам для предотвращения 
возможных ошибок, а также обработке исключений пользовательскими функциями.

В процессе разработки использована система контроля версий согласно стандартам Git workflow. 
Хотя такой подход менее эффективен при индивидуальной работе, он обеспечивает 
строгий контроль качества кода в командной разработке, минимизируя вероятность 
попадания непроверенного кода в релиз. Это существенно повышает надёжность приложения.

## Установка проекта:
В каталоге, где планируется разместить проект, выполняем команду
> git clone https://gitlab.skillbox.ru/evgenii_tiavkin/python_django_diploma.git

Переходим в каталог `cd python_django_diploma` и создаём виртуальную среду окружения
> python -m venv .venv

Активируем среду окружения командой
> source .venv/bin/activate

Устанавливаем зависимости
> pip install -r requirements.txt

Выполнить подготовительные действия для проекта (создать и применить миграции, 
собрать статические файлы, создать администратора, установить необходимые библиотеки)
> cd megano
> 
> python manage.py makemigrations
> 
> python manage.py migrate
> 
> python manage.py collectstatic
> 
> python manage.py createsuperuser
> 
> sudo aptitude install libjpeg libjpeg-dev
> 
> sudo aptitude install libfreetype6 libfreetype6-dev
> 
> python manage.py setup_permissions
> 
> python manage.py create_admin --username shop_admin --email admin@example.com

Запустить сервер: 
> python manage.py runserver

Проект установлен и запущен. Осталось его проверить в браузере. Для этого открыть
страницу http://127.0.0.1:8000/ и залогиниться. И всё, Вы молодец!
